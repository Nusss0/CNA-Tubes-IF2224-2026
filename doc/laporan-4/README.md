# Laporan Milestone 4 — Arion Compiler (Kelompok CNA)

## Cara kompilasi

Butuh distribusi LaTeX (MiKTeX/TeX Live). Dari folder ini:

```bash
pdflatex Laporan-4-CNA.tex
pdflatex Laporan-4-CNA.tex   # ulangi agar daftar isi & referensi terselesaikan
```

atau dengan latexmk:

```bash
latexmk -pdf Laporan-4-CNA.tex
```
